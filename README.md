# GestorServiços - Pacote GitHub Actions

Este pacote contém toda a estrutura de pastas pronta para você subir para o GitHub e gerar o seu APK automaticamente.

## Estrutura dos Arquivos:
- `package.json` (Na raiz)
- `capacitor.config.json` (Na raiz)
- `.github/workflows/build-apk.yml` (Na pasta de automação)
- `www/index.html` (O sistema web)
- `www/manifest.json` (Configuração PWA)
- `www/sw.js` (Service Worker)
